# 副業：せどり・転売戦略（ポケカ／トレカ中心）

メルカリ等での個人転売を、就職後の副業として軌道に乗せるための戦略メモ。
2026年6月時点のリサーチに基づく。

---

## ⚠️ 最重要：始める前提（あつき特有の事情）

せどりの「やり方」より先に、ここが本人にとって最大の論点。

- **生活保護の収入申告は義務**: 受給中に得た転売収入は、ケースワーカーへの申告が必須。
  申告せず稼ぐと「不正受給」になり、返還請求・保護停止のリスク。バレやすい（税・口座・
  フリマの取引履歴）。→ **本格化するなら「生活保護からの自立」とセットで進めるのが筋。**
- **自己破産手続き中の在庫＝財産・浪費リスク**: 手続き開始時点の在庫は管財人の処分対象に
  なり得る。さらに「転売目的の仕入れ」が**浪費**と判断され免責に響いた裁判例もある
  （裁量免責になった例もあるが、リスクとして認識すべき）。
  → **大量仕入れ・在庫を抱える形は、免責が確定するまで控えるのが安全。**
- **結論**: 「趣味で安く買って売る」の延長（不用品・自己使用品の処分）に留めるなら問題は
  小さい。**“事業としての仕入れ転売”を本格化するのは、①免責確定後、②生活保護を抜ける
  目処、の2つが立ってから。** 弁護士・ケースワーカーへの確認を最優先タスクにする。

## 1. リアル店舗・ネット抽選の今の実態（2026）

**徹夜並びの時代は終わりつつある。** 主要販路は「アプリ／ネット抽選」に移行済み。
ポケモンセンターは「実店舗＝LINE抽選／オンライン＝WEB抽選」＋不定期のゲリラ先着、の二段構え。

| 店舗・サイト | 方式 | 応募条件 / ポイント |
|---|---|---|
| ポケモンセンターオンライン | WEB抽選 | 当選率が比較的高い（人気弾で8割当選報告も）。同一住所1BOX制限。「招待をリクエスト」は最長12ヶ月有効で再販ごとに自動抽選 |
| ヨドバシ.com | WEB抽選（ブラウザのみ、アプリ不可） | ゴールドポイントカード＋過去購入履歴が条件のことが多い。応募期間1〜2日と短い。倍率20〜200倍 |
| ビックカメラ | アプリ／特設サイト抽選 | グループアプリから応募 |
| ゲオ | アプリ抽選 | 早朝の並び不要に切替済み |
| ヤマダ電機 | ヤマダデジタル会員アプリ抽選 | アプリ会員登録が必要 |
| トイザらス | 会員抽選 | 会員＋過去1年以内の店舗購入実績が条件 |
| イオン（キッズリパブリック） | 会員限定抽選 | 入荷数が多く当たりやすい傾向 |
| ファミマオンライン | WEB抽選 | 当選品は全国のファミマ店頭受取 |

**実務メモ**
- 「並ぶ」より「**会員登録・購入履歴の事前仕込み**」が勝負。条件付き店舗が多いので、
  発売の数週間前から各サイトの会員ランク・購入履歴を作っておく。
- 一弾につき**応募できる窓口を全部押さえて数を撃つ**のが期待値最大化の基本。
  本人の体感「3〜4割当選」は、窓口を増やすほど安定する。
- 先着・ゲリラ販売は「入荷速報まとめサイト」「店舗X（旧Twitter）」をフォローして通知で拾う。

## 2. 現実的な利益水準（期待値）

ネットの「月利50万」系は上澄み。実態は下記。

- せどり実践者の **63%が月利1万円以下**。月利50万は半年以上本気でやった一部の層。
- 利益率の目安は **20%前後**（回転率とのバランスで選ぶ）。
- ポケカは「BOX転売」より「**当たりカード単抜き**」で跳ねるが、相場知識・状態判断が要る中〜上級向け。

**あつきの場合の見立て**
- 申告ベースで**月8万を記録**できているのは、median（中央値）より明確に上。素質はある。
- ただし抽選依存は**月の波が大きい**。新弾月は跳ね、端境期はほぼゼロになる構造。
- 年間ならし: 抽選転売だけなら **平均で月2〜4万円**に落ち着くのが現実的なレンジ。
  「複数ジャンル（DJ機材・シーシャ・遊戯王・占い書籍）」を足すと、波を埋めて
  **月5〜8万を“平均”として狙える**。波を消す＝ジャンル分散がカギ。

## 3. チェックする時間帯・回数の目安

「24時間いつでも」だが、効くタイミングは決まっている。**1日3チェック＋週次仕込み**で十分。

| タイミング | 何をする | 理由 |
|---|---|---|
| 朝（7〜9時） | 抽選結果確認・当日締切の応募・入荷速報チェック | 抽選結果は朝発表が多い。EC在庫補充も午前帯 |
| 昼（12〜13時） | 新弾告知・応募開始の確認、相場アプリで値動き確認 | 告知は日中に出る。短い応募期間を取りこぼさない |
| 夜（21〜23時） | **出品（売る側）はここ一択**＋メルカリ仕入れ巡回 | フリマが最も動く時間。20〜22時台がゴールデンタイム |

- **売る曜日は土日が最強**。学生狙いのトレカは16〜19時／21〜23時も有効。
- 抽選応募は「告知が出たら即」＋「締切当日の夜にもう一度」の二度押しで取りこぼし防止。
- 仕入れ巡回（メルカリの相場割れ探し）は**夜の1回をルーティン化**。通知（キーワード保存・
  値下げ通知）を仕込めば、貼り付かなくても拾える。ADHD傾向的にも「通知で拾う」設計が合う。

## 4. 販路と手数料（本人の論点①：販路拡大）

**結論：メルカリ一本は卒業。「集客のメルカリ」と「薄利のラクマ／Yahoo!フリマ」を使い分け、
トレカは専用アプリ（magi）も併用。**

| 販路 | 販売手数料 | 立ち位置 |
|---|---|---|
| メルカリ | 一律10% | 集客力No.1。早く確実に売りたい時／高単価で回転重視 |
| ラクマ | 4.5〜10%（実績で変動） | **数を売るほど安くなる**。本格化後のメイン候補 |
| Yahoo!フリマ | 5% | 手数料が安い。薄利・数勝負向き |
| magi（トレカ専用） | 3%＋無料鑑定、委託magiXあり | **トレカはここが本命**。鑑定付きで高く売れやすい |
| スニダン | 鑑定付き売買 | トレカ・スニーカー。利用者600万人/月で流動性高い |

**使い分けの型**: 高く早く売りたい新弾＝メルカリ／薄利の数モノ＝ラクマ・Yahoo!フリマ／
コレクター単価が乗るトレカ＝magi・スニダン。同じ商品を複数に同時出品し、売れたら他を取下げ。

## 5. 画像で「高見え」させる（本人の論点②：画像編集スキル）

**ここがあつきの最大の差別化。** 物販は写真で価格が変わる。編集スキルをそのまま武器化できる。

- 1枚目（サムネ）が命。**白背景・自然光・正方形トリミング**で一覧で目立たせる。
- トレカは**スリーブ／ローダー入りで撮影**＝状態が良く見え、コレクターの信頼が上がる。
- 傷・白かけは**正直に別カットで開示**（クレーム＝低評価を防ぐ。回転率と単価を守る）。
- 1枚目に**控えめな価格・状態テキストを焼き込む**と回遊で目立つ（やり過ぎは規約注意）。
- テンプレ化: 背景・ライティング・トリミングの**自分用プリセット**を作り、撮影〜出品を流れ作業に。
  → 編集が得意なので、ここを「型」にすれば1点あたりの作業時間を圧縮できる＝数をこなせる。

## 6. 法務・税務（最低限おさえる）

- **古物商許可**: 自分で買った**新品（未使用）の転売は不要**。だが**中古を仕入れて反復転売**
  するなら必要（無許可は古物営業法違反＝3年以下の懲役 or 100万円以下の罰金）。
  → 遊戯王・DJ機材・占い書籍など**中古を仕入れて売る**なら、本格化時に許可取得が前提。
- **確定申告**: 就職後の副業なら、**副業所得が年20万円超で申告が必要**。
- **生活保護中は20万円ルールと無関係に全額申告義務**（再掲・最重要）。

## 8. 就職後の副業として軌道に乗せる設計

「労働集約（時間を売る）」にしないことが、本業と両立する条件。

1. **仕入れ判断は本業前後の固定時間（朝・夜の各15分）に圧縮**。残りは通知任せ。
2. **抽選は“自動化”寄り**（招待リクエスト・会員登録の事前仕込み）。当たったら売るだけ。
3. **ジャンルを得意分野に絞る**（ポケカ＋遊戯王＋DJ機材＋シーシャ＋占い）。
   知識のある領域だけにすると、相場判断が速く失敗が減る。
4. **3ヶ月の壁対策**: 飽きやすい特性があるので、「相場が動く新弾月だけ集中、端境期は手を抜く」
   とメリハリをつける。常時フル稼働を前提にしない設計が継続のコツ。
5. **“せどり単体で大きく”を狙わない**。本命は「マーケ×AI×占い」のキャリア。
   せどりは**キャッシュの波を埋める繋ぎ／物販と画像編集の実地練習**と位置づける。

## 9. 利益拡大の打ち手（中期）

- **単抜き挑戦**: BOX転売（薄利）から、相場の効く弾だけ開封→当たりカード単抜きへ。
  ただし相場知識が要る中〜上級。少額から検証。
- **ジャンル分散で波を消す**: 抽選依存を減らし、年間ならしで月収を安定させる。
- **“占い×物販”の合わせ技**: 占い書籍・タロット・パワーストーン等は本人の専門知識が効く
  ニッチ。競合が相場を知らない領域＝旨味がある。護符販売（既存アイデア）とも地続き。
- **画像編集を外販化**: 「高見え出品写真」のノウハウは、他のせどらー向けに**サービス化**
  できる（マーケ×クリエイティブの本筋とも繋がる）。
