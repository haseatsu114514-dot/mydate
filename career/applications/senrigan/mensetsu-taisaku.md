## 0. 面接全体の戦略

**一言で言うと**: 「先生をどれだけ輝かせたか」という貴社の評価軸を、すでに個人事業で実践してきた人間として売り込む。

- **推す順番**: ①プロデュース実績（ライアートで人を売り出した経験）→ ②占い業界での支援実績（紹介文・SNS・ブランディングで先生の指名を増やしてきた）→ ③マーケターとしての客観的視点 → ④AI活用による効率化（会社が推進中の方針と合致）
- **カルチャー上の注意**: 千里眼は「占いに詳しくないスタッフの客観的視点が強み」という文化。**占い師アピールをしすぎると逆効果**。占い師経験は「先生の気持ちがわかる」根拠としてのみ使い、判断軸はマーケター＝客観側であることを明言する
- **競合懸念つぶし**: 個人の鑑定活動（六根清浄）は「入社後は就業規則に従い縮小・停止する前提です」と自分から先に言う
- **成果志向を見せる**: 「週休3日は楽だからではなく、限られた時間で成果を出すプロ集団でありたいから」が会社の公式メッセージ。**「短い時間で成果を出す働き方」への共感**を随所で示す

## 2. 想定問答

### ① 志望動機を教えてください

> 前職で動画編集スクールの受講生やクリエイターの強みを見つけて売り出す仕事をしてきて、2022年からは占い業界で先生方の紹介文やSNSを整える支援をしてきました。自分の戦略で先生の指名が増える瞬間が一番のやりがいです。御社の求人で「先生をどれだけ輝かせたかを評価する」と拝見し、自分がこれまで個人でやってきたことを、そのまま評価軸にしている会社だと感じました。全国85店舗、2026年に100店舗という成長の中で、プロデューサーとして先生と店舗の両方を伸ばす仕事がしたく志望しました。

### ② なぜ占い師ではなく運営・プロデューサー側なのですか？（競合懸念の核心）

> 鑑定の経験もありますが、延べ500名以上を鑑定してきて分かったのは、自分は「一人のお客様を占うこと」より「先生の魅力を言語化して多くのお客様に届けること」に向いているということです。紹介文を書いた先生の予約が増えた時の喜びの方が大きいんです。個人の鑑定活動は、御社の就業規則に従って縮小・停止する前提で考えています。

### ③ 当社は占いに詳しくない社員が多く、その客観的視点を強みにしています。占いに詳しいことはどう影響しますか？（カルチャーフィット確認・この会社特有の質問）

> おっしゃる客観的視点の大切さは、業界にいたからこそ実感しています。私も先生の売り出し方を考える時は、占いの中身ではなく「お客様にどう伝わるか」「数字がどう動いたか」で判断してきました。一方で、先生方は繊細な悩みを抱えることも多いので、現場を経験した人間として先生の気持ちの機微がわかることは、面談やモチベーション管理の場面でプラスになると考えています。判断は客観、寄り添いは共感、と使い分けます。

**ポイント**: 求人票の先輩社員の声にある「先生方は繊細な悩みを持つことも多く、細やかなサポートが必要」という言葉に寄せている。

### ④ フリーランスから正社員に戻る理由は？

> 個人で先生方の支援をしてきて手応えはあったのですが、一人で関われる先生の数には限界があります。約50名の先生を担当し、店舗の運営まで含めて腰を据えて取り組める環境で、実績を積み上げたいと考えたためです。マネジャーから統括まで昇格の道筋が明確なのも魅力でした。

### ⑤ 大学を中退された理由は？（応募前の電話確認とセットで準備）

> 在学中にマーケティングのゼミで学ぶうちに実践への興味が強くなり、実務の世界に飛び込むために退学しました。結果的にコピーライティングやマーケティングを実地で身につけ、前職のスクール事業立ち上げにつながったので、自分にとっては必要な選択だったと考えています。

**ポイント**: 謝らない・言い訳しない。「実践に進むための選択→実務実績につながった」の一本。

### ⑥ 2016年〜2019年（中退後〜ライアート参画前）は何をしていましたか？

> Webマーケティングの現場でインターンとして働きながら、コピーライティングとネット集客を実地で学んでいました。個人でもアフィリエイトで月70万円の成果を出した時期があります。その経験を買われて、前職に業務委託として参画しました。

### ⑦ 2022年6月に前職を退職した理由は？

> 事業の立ち上げが一段落したタイミングで、かねてから学んでいた占いの世界で自分の力を試したくなり、独立を選びました。

### ⑧ 前職の実績を具体的に教えてください

- 受講生約700名・1コース約50万円・売上1億円超の動画編集スクールを立ち上げから運営まで担当
- 教材制作・監修、講師、受講生対応、卒業生への案件差配、部下マネジメント。ホリプロ・専門学校との提携も実現
- **深掘り対策**: 「立ち上げ期は自分が中心で、拡大期はメンバーに任せる範囲を増やした」と役割の変化で語る（千里眼は「チーム制で休んでも回る体制」の会社。一人で抱える人と思われないこと）

### ⑨ 先生のモチベーション管理で大切なことは？

> 先生方は「先生」であって「部下」ではない、ということです。私自身が館に在籍した経験から、先生は管理されることより、自分の価値を理解して扱われることを求めていると感じています。「あなたの強みはここで、こう見せるとお客様に届く」という提案の形で、具体的な数字を一緒に見ながら道筋を描くのが私のやり方です。

### ⑩ あなたの強み・弱みは？

- **強み**: 人の強みを見つけて言語化する力。紹介文・SNS・動画・デザインまで自分の手で作れるので、提案から実行まで速いこと。
- **弱み**: 興味のあることに没頭する反面、複数案件の優先順位づけには意識的な工夫が必要なこと。タスクを書き出して一つずつ処理する運用でカバーしています。

### ⑪ シフト制・土日勤務・月1回の出張は問題ないですか？

> 問題ありません。占いのお客様は土日に動くことは現場経験から理解していますし、週休3日制で回復の時間が確保できるのはむしろ魅力です。出張も、全国の店舗と先生を直接知る機会として楽しみです。

### ⑫ 希望年収は？

> 貴社の規定に従います。

（求人は月給30万〜50万で目標の25万を上回る。**こちらから金額交渉はしない**。試用期間6ヶ月も同条件と明記済み）

### ⑬ いつから勤務できますか？

> 内定をいただければ、個人事業の整理に◯週間ほどいただいた上で入社可能です。

（自己破産・生活保護と就業開始のタイミングは事前に弁護士・ケースワーカーに確認。**面接では一切話さない**）

## 4. 面接で言わないことリスト（重要）

| 話題 | 理由 |
|---|---|
| 生活保護・自己破産・借金 | 法的な告知義務なし。話す必要ゼロ |
| 通院・服薬・ADHD・WAIS | クローズ就活方針。行動レベルの弱み＋対処法で語る |
| 女装風俗・ホスト・スロプロ | 職歴として不要。⑥の「マーケの修行期間」で包括 |
| 情報商材・警察のガサ入れ | 「Webマーケのインターン」とだけ言う |
| 占いの館でのランキング抗議→退職 | 「初月で売上1位」の実績だけ使い、退職経緯は「個人活動に専念するため」に変換 |
| シーシャ屋解雇 | 職歴に含めない |
| 前職のブラック環境批判 | 前職批判は一律NG |
| 「占い師としてもっと稼ぎたい」系の発言 | 競合懸念に直結。プロデューサー志向で一貫 |
| 占いの知識・技術の深さの披露 | この会社は「詳しくない客観視点」を強みとする文化。聞かれたら③の型で返す |

## 5. この求人と自分の相性チェック（求人票原文で更新済み）

| 観点 | 相性 | メモ |
|---|---|---|
| 仕事内容（先生の強み分析・売り出し・面談） | ◎ | 実績・志向とも完全に合致。評価軸「先生をどれだけ輝かせたか」は自分の言葉と同じ |
| 給与（月給30万〜50万） | ◎ | 目標25万を大きく上回る。試用期間も同条件 |
| お客様との対話 | ◎ | 求人票のチャートで「お客様との対話が少ない」「デスクワークが多い」。接客業NGの懸念はほぼ解消 |
| 週休3日・月18日勤務 | ◎ | 体調の波（12〜1月）への備えとしても好条件。「限られた時間で成果」の文化は没頭型と好相性 |
| 創意工夫の多い仕事 | ◎ | チャートで「創意工夫の多い仕事」寄り。0→1気質に合う |
| 通勤（矢場町・栄） | ○ | 名古屋市内から通勤圏。動線は職場見学時に確認 |
| 先生との電話会議（日常業務） | ⚠️ | 「電話はあまりしたくない」傾向あり。ただし性質は会議・面談（ミーティングは可）。1対1の目的ある通話なので許容範囲か、自分の中で確認 |
| 月1回の全国出張（1〜2泊） | ○ | イベント好き・行動力的にはむしろ楽しめる可能性。体調管理だけ注意 |
| 上下関係・裁量 | ⚠️ | 権威との衝突パターンあり。逆質問③で裁量を確認。昇格ルートが明確なのはプラス |
