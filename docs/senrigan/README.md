## この書類の売り込み戦略

**「占い師」ではなく「占い業界を理解しているプロデューサー／マーケター」として見せる。**

千里眼は運営側に占い師を置かない会社なので、「自分が占い師として活躍したい」と伝えると逆効果。あくまで主役は——

1. **プロデュース実績**（ライアートでのクリエイター／タレントの売り出し）
2. **0→1の事業構築・運営力**（700名規模スクールを一人で億規模に）
3. **集客・マーケティング力**（コピーライティング、SNS、アフィリ月70万）
4. **占い業界の現場理解**（鑑定・占い館勤務・占い師支援＝差別化の素材）
5. **AI活用**（拡大フェーズでの生産性）

占い師経験は「だから占い師の気持ちが分かり、採用・定着・マネジメントで信頼を築ける」という**現場理解の根拠**として添える。前面には出しすぎない。

## 面接で聞かれそうな質問と回答の方向性

**Q. なぜ占い師ではなく運営側を志望するのか？**
→ 自分が前に出るより、人の魅力を見つけて売り出す方にやりがいを感じる。ライアートでのプロデュース業務、占い師支援の個人事業がその実証。

**Q. これまで一番の実績は？**
→ 動画編集スクールを一人で立ち上げ、受講生700名・億規模まで育てた話。採用〜育成〜売上管理まで一気通貫した経験は新店展開・店舗運営に直結する。

**Q. 占い師のマネジメントで難しさをどう乗り越える？**
→ 自分も占い師として現場に立ち、占い師同士・占い館運営の難しさ（ランキング、待機、集客の悩み）を体感している。だから占い師の立場を理解した上で運営判断ができる。

**Q. 集客はどう考える？**
→ コピーライティング・SNS・Web広告の実務経験 ＋ AI活用で、占い好き以外の層にも届くコンテンツ設計ができる。
